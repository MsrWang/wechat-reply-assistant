# 微信回复助手（Jev）

Windows 原生微信对话分析与回复起草工具。手动读取当前聊天，核对内容，生成和编辑备选回复；最后由你在微信里发送。**不会后台监听，也不会自动发送。**

当前源码版本：**0.1.6**。主要面向 Windows 11 x64、WeChat Windows 4.x 和 Python 3.11，其他环境需要独立验证。本项目不是微信官方产品。

## 能做什么

- 手动读取当前可见聊天，在发送给模型前核对、编辑或删除消息。
- 分析对方消息，起草不同方向的回复；最后一句是自己发的，也可以主动跟进。
- 双栏工作区、可编辑主草稿、默认展示的其他备选，以及按要求改写。
- 将选中的回复复制，或在目标和消息复核通过后追加到微信输入框；发送由你亲自完成。
- 单个 OpenRouter Key 支持起草和 Jev 判断；可选择只临时使用，或保存到本机 Windows 凭据管理器。

## 从源码开始

在项目根目录的 Windows PowerShell 中：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --require-hashes -r requirements.lock
.\.venv\Scripts\python.exe main.py
```

首次安装依赖需要联网。先进入“示例体验”熟悉操作：不需要 Key 或微信、不调用模型，也不能填入微信。

使用真实分析时，在“设置”中填写**你自己的 OpenRouter API Key**。本仓库没有附带任何可用 Key，也不提供共享账号。模型可用性和费用以服务方为准。

详细的测试、构建和代码入口见 [开发说明](docs/DEVELOPMENT.md)，当前能力和限制见 [项目状态](docs/PROJECT_STATUS.md)。

## 日常使用

1. 在微信打开目标聊天，保持完整可见，点击“读取当前聊天”。
2. 核对预览的文字和说话人，按需补充回应目标，再点击“生成回复”。
3. 选择备选或直接编辑草稿，需要时再发起改写。
4. 复制，或点击“填入微信（追加）”；检查输入框后，**手动发送**。
5. 对方有新消息时重新读取。结束后可“清除本次内容”。

生成和改写使用已确认的快照，不会在生成过程中重新截图。填入前仍严格复核：不确定漏读时拒绝填入并保留草稿供手动重试；明确会话变化时要求重新读取。成功填入一次后，该轮不能再次填入，复制仍可用。

## Key 与隐私

- **支持配置 Key，不等于仓库包含 Key。** 临时 Key 只在本次进程中使用；主动勾选保存时写入当前 Windows 用户的凭据管理器，保存失败不会降级为明文文件。
- 普通偏好位于 `%LOCALAPPDATA%\JevChatPersonal\config.json`，不包含 Key、聊天或分析结果；“忘记已保存 Key”才会删除保存的凭据。
- 截图和 OCR 在本地处理。你确认并发起分析后，确认的文字和分析上下文会发送给 OpenRouter 及所选模型服务。使用前请确认自己有权分享这些内容，并按需删除或脱敏。
- 清除本次内容或退出不能撤回已发出的网络请求；复制/填入会覆盖系统剪贴板，系统或第三方的剪贴板历史可能另外保留内容。
- 不把 Key、真实聊天、截图、运行配置、评估结果或个人日志提交到 GitHub，也不要贴进公开 Issue。测试和示例使用虚构材料。
- 开源仅意味着源码可见，**不是无风险或通过安全认证的保证**。分析里的“真实意图”和概率是模型推断，不代表对方真实想法。

提交或报告问题前请阅读 [贡献说明](CONTRIBUTING.md) 和 [安全说明](SECURITY.md)。

构建需要独立锁定环境；步骤见 [开发说明](docs/DEVELOPMENT.md)。本仓库发布源码，不附带编译后的程序或凭据。

### 历史安装入口

`Install-Jev.cmd` 和传输安装工具仍绑定 **0.1.2**，不要拿来安装 0.1.6。历史 `scripts/build-transfer-bundle.ps1` 生成的 `Jev-Chat-Assistant-0.1.2-win-x64.zip` 仅对应那一版；使用时须通过 `Get-FileHash` 核对哈希，目标电脑仍需进行独立验收。当前版请从源码运行或按开发说明构建完整文件夹版，不要只复制一个 exe。

## 限制

OCR 可能漏读、错读或受画面遮挡影响；语音、图片、屏幕外消息等缺失上下文不会被自动补全。模型可能生成不自然或不准确的建议，特别是日程、经历和承诺，发送前需要人工检查。严格复核可能拒绝填入，这时可重新读取或自行复制判断。

目前没有自动更新、开机启动或无人工确认的发送功能。第三方 Qt 弃用及退出资源警告仍待调查，测试通过不代表所有体验问题已经消失。
