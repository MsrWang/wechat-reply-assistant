# 项目状态

当前源码版本：**0.1.6**，主要面向 Windows 11 x64 / WeChat Windows 4.x。公开仓库仅包含经过隐私整理的源码、虚构测试材料和开发文档，不包含个人运行数据或编译后的程序包。

## 已有能力

- 手动读取并核对当前可见聊天。
- 单个 OpenRouter Key 支持起草与 Jev 判断，可选 Windows 凭据管理器保存。
- 回复和主动跟进模式、逐条分析、可编辑草稿和默认可见的其他备选。
- 双栏/窄窗口切换、黑体及字体回退。
- 复制或经严格复核后追加到微信输入框；每轮成功填入后不可重复执行，永不自动发送。
- 生成和改写使用已确认的快照，不在生成过程中重新捕获微信。

## 优先改进方向

1. 回复自然度、上下文贴合度和真正不同的备选；避免虚构本人经历、日程和承诺。
2. 初次读取、物理遮挡和 OCR 错读的实际体验；不能通过放松身份或内容复核掩盖误读。
3. 首次启动、Key 配置、服务失败提示，以及当前版安装和升级流程。
4. 在回归保护下改善较大界面/控制器文件的可维护性。
